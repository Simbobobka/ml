# ML-1: Лінійна регресія, оптимізація та статистичний аналіз

Ноутбук: `lab1_linear_regression.ipynb`

Датасет: House Prices (Ames Housing), Kaggle "House Prices - Advanced Regression Techniques", файл `data/train.csv`.

## Запуск

```bash
pip install numpy pandas matplotlib scipy scikit-learn jupyter
jupyter notebook lab1_linear_regression.ipynb
```

Лінійна регресія, функція втрат, градієнти та всі варіанти градієнтного спуску реалізовані на numpy.
scikit-learn використовується лише для розбиття вибірки, One-Hot Encoding та StandardScaler.
