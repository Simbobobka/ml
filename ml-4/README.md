# ML-4: дерева рішень та ансамблеві методи за наявності пропущених значень

Ноутбук: `lab4_trees_ensembles.ipynb`

Індивідуальний варіант: N = 8, отже SEED = 42 + 8 = 50.

## Дані

Датасет Annealing. Методичка пропонує `fetch_openml(name='anneal', version=1)`, але на момент виконання
роботи OpenML повертав HTTP 503, тому дані взято з першоджерела UCI
(https://archive.ics.uci.edu/dataset/3/annealing) і збережено у `data/anneal.csv`.

Використано повну версію з 898 спостережень (anneal.data 798 рядків плюс anneal.test 100 рядків),
що відповідає версії OpenML: той самий розмір, ті самі 38 ознак і той самий розподіл класів.

## Запуск

```bash
pip install -r requirements.txt
jupyter notebook lab4_trees_ensembles.ipynb
```

Повне виконання (Restart & Run All) займає близько 8 хвилин, найдовший крок це вкладена крос-валідація
з Optuna (3 моделі x 5 зовнішніх блоків x 30 trials).

## Короткий результат

Індикатори пропусків дають приріст macro F1 від 0.057 до 0.068 для всіх трьох моделей.
Найкраща якість у дерева рішень (0.9903 на крос-валідації), але різниця з ансамблями
статистично не значуща за тестом Наде-Бенжіо.
